# Snow 数据特点与研究假设、文献阅读记录

日期：2026-10-05。对应实验记录 EXP-0002 至 EXP-0004。

本报告区分本地实测、提供方说明、论文结果和我们的建议。仅进行压缩包目录核查及少量栅格抽样，未清洗、拼接或更改原始数据，未开始聚类实验。

## 1. 本地数据实际覆盖

扫描 `data/snow depth/` 的全部 55 个压缩包，压缩文件合计 358,045,558 字节，约 358.05 MB / 341.46 MiB；共有 23,557 个带日期的数据文件，包含不同产品在同一天的重复覆盖，不能当作独立日数。另有两份 DOC 说明。压缩包目录及四个主序列栅格抽样扫描耗时约 3.18 秒。

| 产品或分组 | 本地文件名对应日期范围 | 数据文件数 | 格式与完整性 |
| --- | --- | ---: | --- |
| 长期主序列 `snowdepth-YYYY`，说明标注来源为 SMMR / SSM/I / SSMIS | 1979-01-01 至 2020-12-31 | 15,331 | 42 个年度包；TXT；1980–2016 的十个闰年各缺第 366 日，2020 有 366 日 |
| `闰年最后一天.rar` | 1984、1988、1992、1996、2000、2004、2008、2012、2016 的 12-31 | 9 | 无头 TXT 抽样；补齐上述九日，仍无 1980-12-31 |
| AMSR-E | 2002-06-29 至 2011-09-27 | 3,378 | 10 个年度 RAR；TXT；在上述起止日期之间，文件日期连续 |
| AMSR2 较早包 | 2012-09-01 至 2024-08-31 | 4,383 | 带头 TXT 抽样；文件日期连续；命名为 YYYYMMDD |
| AMSR2 最新包 | 2024-09-01 至 2025-11-30 | 456 | GeoTIFF；文件日期连续；包名中的“2024-08”不等于包内起始月份 |

这里的“连续”只指日期文件存在，不能证明每个像元每天有效，也不能证明压缩包内所有文件都可完整解码。

**结论**：本地资料总体涉及 1979–2025，但不是一套已经同质化的 1979–2025 连续产品。长期主序列本地止于 2020；2021 之后仅在 AMSR2 产品中有覆盖。不能把不同传感器同日文件按名称合并或覆盖。

README 计划的 2000/01–2013/14 雪年，对应 **2000-08-01 至 2014-07-31，共 5,113 天**。主序列年度包缺其中四个 12-31，补充包都有对应文件；因此该时段在文件日期层面可以补齐。补充文件的格式、掩膜和数值一致性仍需专门检查。

地理范围是产品矩形网格范围，不能自动当作中国国界掩膜或青藏高原边界。README 的 73–105°E、26–40°N 是候选研究窗口；按中心坐标含两端计算为 129 × 57 = 7,353 格，约 3,800 个最终节点尚待高原掩膜及雪日筛选验证。

### 格式和地理定位差异

- 主序列 `YYYYDDD.txt` 中的 DDD 是年内日序号，必须按真实日历解析。闰年第 366 天是 12 月 31 日，不是 2 月 29 日。
- 实测 AMSR-E `2002180.txt`、主序列 `2020/2020001.txt`、补充包 `1984366.txt` **没有六行头信息**，完整数组都是 161 × 321。读取器应先识别格式；不能对所有 TXT 固定跳过六行。
- AMSR2 `20120901.txt` 的头信息与旧主序列相同，声明 `NODATA_value=-1.00`。
- 最新 AMSR2 检查了 `20240901.tif`、`20250101.tif`、`20251130.tif`：三者均为 EPSG:4326、161 × 321、0.25°；外边界是 **[59.875, 15.125, 140.125, 55.375]**。据此计算的纬度中心范围是 **15.25–55.25°N**，比旧 TXT 声明整体向北一格。这里只确认元数据差异，尚不能确定是数据真的换了网格，还是地理标注错误；禁止默默移位修正。
- 无头 TXT 缺少自身地理参考；相同行列数不构成坐标方向和配准一致的充分证据。尤其补充包的掩膜、舍入位数也有差异，加入主序列前需核对。

### 原始数据抽样范围

主序列读取了 `1979001.txt`、`2000001.txt`、`2008001.txt`、`2014001.txt` 的完整数组：均为 161 × 321，最小值 0，最大值分别为 37.89、43.22、27.29、28.84 cm。这里只报告样本范围，不将其当作全数据范围。

最新 TIFF 首个样本最小值 -1，最大值约 34.293；Float64 也不构成更高物理精度的证据。尚未核实该最新产品的单位与算法版本是否完全沿用旧说明。

## 3. 数据质量与精度如何表述

**本地说明**：《中国长时间序列雪深数据集介绍.doc》声明更新到 2021 年末，SMMR 时段填补可能用到前后最多 7 天的数据；制作流程另写使用此前最近数据填补，两处描述不完全相同。因此要记录“存在时间填补，具体版本规则待核实”，不能一概声明全部是向前填补。其 2021 年说明还提到改用 EASE-Grid2、F18/F16，且与 F17 未做交叉订正，随后拟转 AMSR2。**这些是说明中的声明，本地没有 2021 主序列包供核查。**

**雪深验证误差**：Che 2008 在其站点验证中，约 65% 的绝对误差小于 5 cm；SMMR 和 SSM/I 的误差标准差分别为 6.03 和 5.61 cm。对应验证数据为 1983–1984 年 SMMR 和 1993 年 SSM/I，图 6 标注样本数分别为 2,070 和 6,862。这不是当前所有年份、所有像元的统一 RMSE，更不是整个青藏高原的误差保证。[Che 2008](https://doi.org/10.3189/172756408787814690)

**高原适用性**：Dai 2017 的 AMSR-E/AMSR2 评估指出粗分辨率、薄雪、地表温度、地形和站点代表性影响结果；其中以 MODIS 雪盖比例 >10% 为有雪标准时，雪盖识别总体准确率为 66.7%。这是特定研究设置下的雪盖分类准确率，**不是雪深准确率，也不能直接赋给我们全部主序列**。[Dai 2017](https://tc.copernicus.org/articles/11/1933/2017/)

实际报告建议表述为：“日尺度、0.25°网格的被动微波雪深反演产品，存在时间填补与空间相关误差；物理精度随地表条件、传感器和验证方式变化。”暂不赋予统一精度百分数。

## 4. README 的 thesis 与三个假设

**核心问题**：仅用雪季的积累、维持、消融形状建立 kNN 图，能否得到与青藏高原环流背景一致的空间分区？边界是锐利分界，还是随年份移动的过渡带？

| 假设 | 当前设想 | 阅读后的判断与建议 |
| --- | --- | --- |
| H1 分区 | 图分区与西风、过渡、季风格局一致，且不能只由海拔解释 | 有物理动机，仍须检验。建议建图特征只用雪，地理位置及环流信息留作验证，避免把预期答案写入特征；不能预设必须得到三个簇 |
| H2 边界 | 边界是宽阔且逐年变化的带 | 属于待证假设。特征图上的邻域不等于地图上的邻域，低局部聚类系数并不必然代表地理边界；逐年比较要固定或显式协调节点集合、对齐簇标签，并检查参数敏感性 |
| H3 混杂 | 海拔、冰川与传感器变化可能解释部分分区 | 文献与本地格式核查都说明这一检查有必要；另需考虑湖泊、薄雪、地表温度、填补与掩膜差异 |

**方法上的待明确项（建议，尚未实施）**：

1. “每年至少 30 个雪日”应明确是每个雪年都满足还是多年平均满足，且应定义有雪阈值；不能用存储小数位推断可靠检测阈值。
2. temporal HOG 的 `arctan(雪深变化率)` 会随雪深单位、振幅和时间尺度变化；L2-Hys 不会自动让分箱对振幅缩放不变。因此 README 的“不看雪量”目前是目标，尚非已证明性质，需用幅度缩放对照检查。
3. 若一年 24 个半月 cell、两 cell 一 block、步长一且不环绕，共 23 blocks，维度为 23 × 2 × 6 = 276；若采用环绕或补边形成 24 blocks 才可为 288。README 的 288 需要补充具体 block 规则；闰日处理也需明确。
4. Jensen–Shannon/Hellinger 用于分布时，需将非负特征按总和归一化并定义全零特征的处理。L2-Hys 本身不保证总和为 1。
5. 多年平均特征可用于整体分区；逐年移动必须由逐年特征和图检验，平均后无法直接恢复逐年变化。
6. README 列出的 DEM 数据与冰川表当前未在 data 目录找到；“DEM band”“82 条记录的坐标和字段”等尚未完成本地文件核验，不能写成已具备验证资料。

## 5. 六篇引用论文阅读笔记

阅读范围：四篇已取得全文并阅读与本任务有关的数据、方法、验证及结论部分；Xiong 两篇目前只读到机构摘要或出版方索引片段，全文访问受阻。以下逐篇标注，不把摘要阅读称为全文精读。

### Che et al., 2008：雪深产品如何反演

[Snow depth derived from passive microwave remote-sensing data in China](https://doi.org/10.3189/172756408787814690)。已取得 10 页全文，阅读算法、精度验证和不确定性章节。

用中国站点数据调整 Chang 算法，结合地表分类，考虑植被、湿雪、冷沙漠、冻土及季节性雪粒径/密度变化。日产品包含覆盖间隙填补。对我们而言，雪深曲线同时包含自然过程与反演、填补处理的影响，不能将所有逐日跳变都解释为降雪或消融。验证数字及适用范围见第 3 节。

### Dai, Che & Ding, 2015：跨传感器一致性

[Inter-Calibrating SMMR, SSM/I and SSMI/S Data to Improve the Consistency of Snow-Depth Products in China](https://doi.org/10.3390/rs70607212)。已取得 19 页全文，阅读数据、交叉订正方法及结论；出版方可下载副本：[PDF](https://res.mdpi.com/d_attachment/remotesensing/remotesensing-07-07212/article_deploy/remotesensing-07-07212.pdf)。

研究使用传感器重叠期做亮温回归校准。SSM/I 与 SSMIS 的全国雪盖面积相对偏差由 42.42% 降至 1.65%，雪深相关汇总量的偏差由 66.18% 降至 -1.5%；这些是产品间一致性指标，不能理解为与地面真值的误差。对我们而言，应保留传感器时期信息，尤其检查研究窗口内约 2008 年的转换，不能因“已校准”就假定无残余影响。

### Dai et al., 2017：高原上的局限

[Evaluation of snow cover and snow depth on the Qinghai–Tibetan Plateau derived from passive microwave remote sensing](https://tc.copernicus.org/articles/11/1933/2017/)。已取得 16 页全文，阅读数据、验证、误差成因与结论。

结合 MODIS、站点和实地采样评估 AMSR-E/AMSR2 产品，强调地形异质性及单个站点对大网格的代表性问题。它为 H3 和掩膜、敏感性检查提供依据；它不直接证明我们图上的簇就是气候区。涉及冰川湖泊的误差也不能一概描述为“冰误读成雪造成高估”，文中还观察到这些区域的低估。

### Xiong et al., 2017：融雪时间携带气候信号

[Snowmelt Pattern Over High-Mountain Asia Detected From Active and Passive Microwave Remote Sensing](https://doi.org/10.1109/LGRS.2017.2698448)。已读[作者机构收录摘要](https://experts.illinois.edu/en/publications/snowmelt-pattern-over-high-mountain-asia-detected-from-active-and/)，未取得可完整核读的全文。

摘要报告利用长时间被动微波和十年主动微波估计融雪初始日期；主动微波为 4.5 km，被动微波为 25 km。其时间分析显示多数区域融雪提前，喀喇昆仑及部分西昆仑例外，并报告与气温的关联。它支持将“时间形状”作为研究变量的动机；本文方法细节与可靠性评估尚未全文核验，不能据此直接实现算法。

### Xiong et al., 2019：高亚洲融化时间的区域变化

[高亚洲地区冰雪融化时间变化](https://doi.org/10.1360/TB-2019-0085)。已读出版方索引中的中英文摘要片段；[出版方 PDF 地址](https://www.sciengine.com/parse/pdf/0023-074X/1715B09364D84ED89FA0AEC7DFDC70F6.pdf?attname=Change+of+snow+and+ice+melting+time+in+High+Mountain+Asia.pdf)直接获取失败，未完成全文阅读。

摘要说明使用 1979–2018 年微波辐射计资料估计融化初始时间，并结合 ERA5 分析不同区域的变化。对我们而言，融雪时序可作外部比较变量；不过其数据集中的 DEM 波段、单位和网格必须实际检查，本文摘要不能验证 README 的“DEM band”假定。

### Yao et al., 2012：冰川差异与环流背景

[Different glacier status with atmospheric circulations in Tibetan Plateau and surroundings](https://doi.org/10.1038/nclimate1580)。已取得并阅读 5 页论文正文；[作者机构 PDF](https://byrd.osu.edu/sites/default/files/2020-12/Yao%20et%20al%20Nature%20Clim%20Change%202012.pdf)。未取得并逐条核对补充表 S4。

论文综合 82 条冰川退缩记录、7,090 条冰川面积变化及 15 条质量平衡记录，按七个地理区域和三条气候梯度剖面讨论差异。东南部/喜马拉雅退缩较强，东帕米尔较弱；环流与降水变化是解释的一部分。它支持 H1 的物理背景，但不能简化成“整个西北都稳定或前进”，也没有给出适用于全部雪深格点的三分类真值。验证时应注意研究时段、空间尺度与冰川样本选择差异。

## 6. 建议的下一步与本次边界

建议下一步在用户指导下确定主序列及研究时段，建立只读的日期、格式和坐标检查，再决定研究区掩膜与有雪阈值。就现有 README 而言，2000-08-01 至 2014-07-31 的主序列具备文件日期条件，但补充日与主序列的一致性还未验证。

本次未做全时段像元缺失率、气候趋势、雪日筛选、HOG 或聚类；未验证实际精度，未改写 README 的 thesis。四篇全文阅读与两篇摘要阅读的范围如上，TPDC 当前网页未返回可读元数据，故不把 README 的最新标题、许可和大小当作已在线复核的信息。
