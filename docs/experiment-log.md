**Part II 要求梳理**：

1. **E-1 数据与特征**：选择与研究目标相关的数据，将属性转换成特征向量，特征维度作为超参数；说明数据与特征提取方法。
2. **E-2 两两关系**：构建全体样本之间的加权关系矩阵，说明所用相似度、距离或其他关系量。

4. **E-4 组合连通性分析**：对每个较大的连通分量，绘制度分布与局部聚类系数分布，并描述分布类型。
5. **E-5 拉普拉斯谱分析**：对每个较大的连通分量构建归一化拉普拉斯；若图在某个 k_c 后连通，观察 k 增长时 Fiedler 值 λ₂(k) 的变化；做三维不变子空间嵌入；绘制约 2^5=32 个最小特征值，选择与其余谱分离良好的非零单特征值，按对应特征向量的节点域划分图，在该向量和另外两个特征向量构成的三维嵌入中着色，并联系原始数据解释。
6. **E-6 可选扩展**：尝试其他图聚类或分割方法。
7. **E-7 讨论**：总结观察到的关键性质和初步发现。

**用户要求及澄清**：新建文件夹，用 Python 开展基础梯度/HOG 特征观察并配置独立环境。用户确认两种二维 histogram 均展示，并要求在文档、代码和展示中详细注明。

**输入及范围**：主序列 2000-08-01 至 2014-07-31，73–105°E / 26–40°N 矩形，57 × 129 格，完整日历 5,113 天，读到 5,109 个日文件。2000/2004/2008/2012 的 12-31 补丁因一致性未核实暂不并入，保留 NaN。未应用高原边界及 30 雪日门槛。每个源压缩包的 SHA-256 随输出保存。

**方法及超参数**：

- 时间：一天后向差分 `D(t)-D(t-1)`，cm/day；缺日和受影响的翌日不产生梯度。
- 空间：东西、南北中心差分，cm/km；使用 111.2 km/° 及经向纬度余弦；北向为正，完整五点模板用于空间方向，外围一圈排除。
- 二维图一：东西 × 南北梯度。二维图二：时间梯度 × 同日空间梯度幅值。两者各 100 × 100 bins，对数颜色表示原始计数，按各轴绝对梯度 99.5% 分位数限幅，并注明图外比例。
- 一维计数同时比较全部有效与有雪参与模板（至少一个深度 >0），保留零变化。18-bin 时间 HOG 用 `atan(g_t / 1 cm/day)` 和绝对变化权重；18-bin 空间 HOG 用 `atan2(g_N,g_E)` 和空间幅值权重。
- 各格点按公历月跨年份池化并 L1 归一化，导出两组 (7353,216) 特征，保留原始权重、样本计数和坐标。尚未做空间 block L2-Hys；这套定义与主 README 的半月 288 维设想分别记录。没有随机抽样或随机步骤。

**尝试、更改与验证过程**：

1. 首次静态检查发现一个未使用导入与长行格式问题，删除无用导入并格式化后通过。Basedpyright 零错误、零警告。
