## 图 1：梯度分布与 HOG

![时间空间梯度一维分布与方向直方图](../feature_extraction/outputs/exp-0005-primary-2000-2014-v2/01_distributions.png)

上左：一天前后雪深差，单位 cm/day；上右：中心差分得到的空间梯度幅值，单位 cm/km。分别展示全部有效样本和“差分涉及的像元中至少一个雪深 >0”的样本，保留零梯度。纵轴为每 bin 占全部对应样本的比例，使用对数坐标。显示范围取有雪样本绝对梯度的 99.5% 分位数，尾部未重新归一化。

下左：时间角度 `atan(g_t / 1 cm/day)`，18 个方向 bin，按 `|g_t|` 加权；下右：空间角度 `atan2(g_N,g_E)`，18 个有符号方向 bin，按空间梯度幅值加权。方向权重各自归一化为 1。平坦样本在 HOG 中贡献零权重。

| 统计项 | 时间梯度 | 空间梯度幅值 |
| --- | ---: | ---: |
| 全部有效样本数 | 37,529,712 | 35,686,365 |
| 有雪参与样本数 | 9,429,315 | 12,012,443 |
| 全部有效样本中恰为零 | 83.97% | 66.60% |
| 有雪参与样本中恰为零 | 36.21% | 0.78% |
| 有雪参与样本的中位数 | 0 cm/day | 0.05016 cm/km |
| 有雪参与样本的四分位范围 | -0.29 至 0.30 cm/day | 0.02487 至 0.08992 cm/km |
| 全部有雪样本范围 | -45.33 至 45.33 cm/day | 0 至 0.92492 cm/km |

**观察**：零值对分布影响很大；限定有雪参与后，时间序列中依旧存在大量平坦相邻日。原因可能包括稳定雪深、产品填补、舍入和反演方法，本次未进行归因。时间方向图出现正负两侧较高权重，但 arctan 变换和幅值加权会改变峰形，不能由此判定原始雪深具有两个气候类别。极端日变化也需要后续定位，尚未作为物理积累/消融事件确认。

## 图 2：两种二维直方图

![空间梯度联合直方图与时空梯度联合直方图](../feature_extraction/outputs/exp-0005-primary-2000-2014-v2/02_joint_distributions.png)

**左图：东西梯度 × 南北梯度。** 横轴 `g_E`，纵轴 `g_N`，均为 cm/km。向东/北雪深增大分别为正值。样本要求中心及东、西、南、北五点有效，且其中至少一个雪深 >0。中心差分使用约 111.2 km/° 和纬度余弦换算，空间边界排除。

**右图：时间梯度 × 空间梯度幅值。** 横轴 `g_t = D(t)-D(t-1)`，单位 cm/day；纵轴同日 `sqrt(g_E²+g_N²)`，单位 cm/km。时间和空间梯度均有效，且时间或空间模板有雪参与才计入。两轴单位不同，本轮只研究联合计数，不将其合成方向角。

两图都是 **100 × 100 等宽分箱**，颜色是原始样本数的对数映射，白色代表空 bin。每轴以各自样本的绝对值 99.5% 分位数限幅，落在显示范围之外的联合样本比例分别为 **0.89% 和 0.94%**。这些是显示截取，HOG 特征仍使用全部有效梯度。

**观察**：空间联合分布集中于原点附近，在坐标轴附近有明显细脊；时空图在时间变化接近零处有竖向高计数带。这说明“当天雪深基本不变”和“空间上存在雪深差异”可以同时发生。这里只进行形状描述，没有做独立性检验、拟合分布族或气候归因。轴向结构可能与产品重采样、舍入或地理场有关，尚未排除这些解释。

## 图 3：逐月方向分布

![逐月时间和空间方向分布](../feature_extraction/outputs/exp-0005-primary-2000-2014-v2/03_monthly_hog.png)

横轴为上述有符号方向角，纵轴公历月。跨年份、跨格点累积原始梯度权重，再在每个月内归一化，因此梯度强的样本贡献更大。左右图色标独立。该区域图的汇总方式与导出的“逐像元逐月归一化”特征不同，二者在代码和图注中均有说明。

| 月份 | 减少方向占当月时间梯度总权重 | 增加方向占比 |
| --- | ---: | ---: |
| 5 月 | 54.23% | 45.77% |
| 6 月 | 54.79% | 45.21% |
| 10 月 | 41.51% | 58.49% |
| 11 月 | 43.53% | 56.47% |

**观察**：季节性的增加/减少权重发生变化，有进一步分析的价值。空间方向中 80–100° bin 在各月汇总中权重最高，表示向北雪深增大的梯度贡献较多；它是雪深场的梯度方向，不能理解为风向或雪移动方向。当前矩形包含高原周边、粗网格和可能的产品方向性，尚未解释成环流证据。

## 导出的特征及其限制

[hog_features.npz](../feature_extraction/outputs/exp-0005-primary-2000-2014-v2/hog_features.npz) 包含每个格点 **216 维时间 HOG** 和 **216 维空间 HOG**，均为 12 公历月 × 18 bins。另存原始权重、归一化数组、有效有雪样本数及坐标。

时间特征有 1,572 个格点整行全零，空间特征有 1,357 个格点整行全零。全零可能意味着无非零梯度或无可用样本；空间边界也会造成全零。后续使用距离度量或建图前需结合有效计数筛选，不能把所有零向量当作同一种气候。

本轮是基础的幅值加权方向统计，尚未做空间 cell/block 的 L2-Hys，也未实现主 README 的半月 288 维设想。时间角度的参考尺度固定为 1 cm/day，分箱数 18；这些参数会影响图形，不能把当前峰形视为对参数不敏感的结论。
