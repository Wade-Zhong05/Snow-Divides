## “3D Laplacian invariant subspace colored by Fiedler domains” 是什么

这里的每一个点是一个**地理网格格点**，但绘图位置是图的归一化拉普拉斯矩阵的第 2、3、4 个特征向量在该节点的取值 `(q₂,q₃,q₄)`。三个轴没有经纬度或雪深单位。更准确地说，图展示的是前三个非平凡拉普拉斯特征向量构成的谱坐标。原静态图的颜色来自 `q₂` 的符号：蓝色为负、橙色为正、灰色为零附近的待定点。严格零带通常没有灰点；符号方向由代码固定，仅供本次显示。

因为横轴就是 `q₂`，再按 `q₂` 的正负着色，蓝橙两侧沿横轴分开是**定义造成的**，不能当作独立的三类或气候分区证据。旋转时重点看 `q₃/q₄` 方向的形状、重叠、细长桥接和离群点，再和原始地理网格图逐点对照。特征向量的整体符号可反转；若特征值接近，三维基底也可能改变朝向，解释应以分区关系和稳定性为主。

[打开可旋转的离线 3D 图](../outputs/exp-0010-views-from-exp-0009/05_embedding_3d_interactive.html)。双击 HTML 文件在浏览器打开即可离线使用。按住鼠标左键拖动旋转，滚轮缩放，悬停读取原网格索引、经纬度、三类标签和谱坐标；左上菜单可在 **Fiedler 两侧**与**默认三类谱聚类**之间切换颜色。图例可隐藏或显示某一组。要看点在真实地理空间的位置，用悬停经纬度查下述地图，不要把三维坐标轴当作地图轴。

## 二维矩阵版聚类图

![同一三类顺序下的距离矩阵与 kNN 邻接矩阵](../outputs/exp-0010-views-from-exp-0009/06_clustered_matrices.png)

这张图把三类标签相同的格点排在一起，**同时按相同顺序重排矩阵的行和列**。同一类内部保留原始地理网格索引顺序。橙线标出 `C1/C2/C3` 边界，主对角线上的三个方块位置因此必然存在；研究对象是块内和块间的数值与连线密度。

- 左侧 `D` 是 E-2 的全体两两雪特征欧氏距离，黄绿较近、蓝紫较远。它是稠密矩阵，主对角线为同一个格点与自己的零距离。不是地理距离。
- 右侧 `W(21)` 是 E-3 的对称 kNN 图；每个蓝点表示**存在一条非零权重边**，空白表示没有边。点的颜色不编码边权，且图只显示筛选后的边，因此不能把右图的空白直接读成“雪特征非常远”。矩阵关于主对角线对称。
- 当前三类的大小为 `1951/1611/379`。`W` 的同类非对角边密度约为 `1.46%/1.77%/6.79%`；`C1–C2`、`C1–C3`、`C2–C3` 分别约为 `0.092%/0.124%/0%`。比较密度时要考虑类大小，不能只比较点的绝对数量。左图各同类块的平均 `D` 约为 `0.324/0.350/0.190`，`C1–C2`、`C1–C3`、`C2–C3` 跨类块约为 `0.428/0.401/0.580`。这些值属于本次雪特征定义。

三类标签由 `W` 的拉普拉斯计算，而 `W` 又由 `D` 构造，所以块内连边更密、距离常较小是当前算法的**内部一致性检查**，不能独立证明三个真实气候区。要检验气候解释，仍需原地理图及外部气候/地形资料。

## 每张图怎么用

| 图 | 建议看的问题 | 读图限制 |
| --- | --- | --- |
| [E-3：k 扫描连通性和 λ₂](../outputs/exp-0009-part2-default-v3/e3_knn/connectivity_and_fiedler.png) | 先排除断开的参考图；再看不同 `k` 下 λ₂ 与稳定性。当前 `k=3` 起连通，参考 `k=21`。 | λ₂ 越大并不自动代表分区越合理；还须看 `k_scan.json` 的 ARI。 |
| [E-5：特征值与 eigengap](../outputs/exp-0009-part2-default-v3/e5_laplacian/01_laplacian_spectrum.png) | 寻找候选类数及谱间隙。当前 `m=2,3,5` 后的间隙接近。 | 没有唯一明确的三类证据；默认三类来自待检验的气候假设。 |

| [E-5：单独三类原地理图](../outputs/exp-0009-part2-default-v3/e5_laplacian/02_reference_clusters.png) | 看三类在经纬度网格上的连续性；这是地理解释的入口。 | 灰色是不参与本轮分析的格点；类别颜色还不能直接命名为气候区。 |
| [E-5：Fiedler 严格切分及 10%/20% 近零带](../outputs/exp-0009-part2-default-v3/e5_laplacian/03_fiedler_maps.png) | 看二分边界对接近零的点有多敏感。 | 灰色近零带是算法敏感性标记，不是已测得的物理过渡带。 |
| [E-5：静态三维谱坐标](../outputs/exp-0009-part2-default-v3/e5_laplacian/04_embedding_3d.png) | 在报告中固定视角展示 `q₂,q₃,q₄` 的形状。 | 投影会遮挡重叠；需配合可旋转版。 |
| [可旋转三维谱坐标](../outputs/exp-0010-views-from-exp-0009/05_embedding_3d_interactive.html) | 旋转、缩放、悬停定位具体格点，并切换 Fiedler/三类颜色。 | 三轴是图的谱坐标，不是经纬度/雪深；Fiedler 横向分开有定义成分。 |

建议顺序：先在原地理网格上看聚类位置，再看特征值和不同类数是否支持该划分，接着用二维矩阵检查连接结构，最后用三维图旋转检查谱坐标中的重叠和个别点。三维图菜单切换到三类标签时，可与单独三类地理图对应。

## 代码复现与位置

从项目根目录运行；`outputs/exp-0010-views-from-exp-0009/` 是这次已生成的输出，复现时应换一个尚不存在的目录名：

```bash
uv sync --locked
uv run python export_views.py \
  outputs/exp-0009-part2-default-v3 \
  outputs/my-matrix-and-3d-views
```

`export_views.py` 从原运行读取 `e1_features/features.npz` 的格点映射和经纬度、`e2_interactions/distance_matrix.npy` 的 `D`、`e3_knn/graph_k21.npz` 的 `W`、`e5_laplacian/spectral_results.npz` 的向量与标签，并从 `manifest.json` 读取参考 `k` 与聚类数；不重新求特征或谱。后续直接运行根目录 `pipeline.py` 时，E-5 会自动写出 `05_embedding_3d_interactive.html` 和 `06_clustered_matrices.png`。两图的实现分别在 `snow_divides/e5_laplacian/interactive.py`、`matrices.py`。

本次程序检查了离线 HTML 内嵌 Plotly、图层切换、滚轮缩放设置与悬停字段，并成功运行新的 pipeline；由于当前计算机界面权限不足，未能在浏览器中亲自拖动验证。用户打开 HTML 后若有渲染问题，应保留文件并记录浏览器及现象，作为下一次实验追加处理。
