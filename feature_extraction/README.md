# 雪深梯度与 HOG 初步特征提取

实验 EXP-0005。本轮目的：观察雪深在时间与空间上的变化分布，保存可复用的方向直方图特征。用户要求的两种二维直方图均有实现，并在图内给出算法、单位、样本条件和显示范围。

## 运行环境

```bash
cd feature_extraction
uv sync --locked
uv run python run.py --help
uv run python run.py
```

`uv` 在本目录建立 `.venv`；`uv.lock` 固定依赖版本。已有 Conda 安装提供了本次使用的 Python 解释器，依赖安装在独立 `.venv` 中。也可先 `source .venv/bin/activate`，再执行 `python run.py`。`run.py` 中的 PEP 723 元信息仅供独立脚本执行参考；复现本实验使用上述项目锁文件命令。

默认时间为 2000-08-01 至 2014-07-31。指定其他日期和输出目录：


日期目前限于已核查的带头主序列 1979–2014。已存在的输出目录会被拒绝，以保存历史结果。默认目录名使用运行时的本机时间。

## 数据范围与读取规则

- 来源：`../data/snow depth/snowdepth-YYYY.tar.gz`。逐包流式读取，保留每个输入压缩包的 SHA-256。
- 范围：经度中心 73–105°E、纬度中心 26–40°N，含两端，共 **57 × 129 = 7,353 个格点**。这是矩形窗口，尚未应用高原多边形或“每年至少 30 个雪日”筛选。
- 栅格按 ASCII Grid 的首行在北约定，纬度从 40°N 向南递减；列由西向东。
- 读取器要求并验证 161 × 321、0.25°及既有中心坐标的六行头。发现不支持的格式就报错；不猜测无头文件的地理参考。
- 雪深单位 cm；负值转为 NaN。零值保留为产品报告的零雪深，不能由此排除原产品已填补或误检。
- 创建完整日历。四个 12-31 补充文件因配准、掩膜和舍入差异未核实，本轮暂不合并；空缺日期整层为 NaN，前后时间差分自然缺失。
- 同时存在的 AMSR-E、AMSR2 产品不参与本轮计算。

## 梯度的准确含义

记 `D(t,r,c)` 为雪深，单位 cm。

### 时间梯度

`g_t(t,r,c) = [D(t,r,c) - D(t-1,r,c)] / 1 day`，单位 **cm/day**，归属于后一天 t。

正值表示产品雪深增加，负值表示减少。减少可能包含融雪、沉降、风吹搬运或反演误差，不能单凭符号认定融雪。首日、缺失日及其翌日不计算梯度。日期间隔固定为一天，禁止跨缺测连接。

### 空间梯度

采用中心差分，只计算有完整相邻像元的内部点：

```text
dx(latitude) = 111.2 × cos(latitude) × 0.25 km
dy           = 111.2 × 0.25 km
g_E = [D(r,c+1) - D(r,c-1)] / (2 dx)
g_N = [D(r-1,c) - D(r+1,c)] / (2 dy)
g_S = sqrt(g_E² + g_N²)
```

`g_E` 为向东的变化率，`g_N` 为向北的变化率，`g_S` 为空间梯度幅值，均为 **cm/km**。这是按地理距离估算的水平差分，未计算山地坡面距离。中心差分跨越两个相邻网格间距；其尺度约为数十公里，不能解释小尺度雪面纹理。

二维空间分布和方向特征要求中心与东、西、南、北五点全部有效；矩形最外围一圈排除。单独的东西或南北导数只要求相应三点有效。

## 两种二维 histogram：必须分清轴与样本

两者在 `02_joint_distributions.png` 并排显示，代码为 `plots.joint_distributions()`。

| 内容 | 左图：空间联合分布 | 右图：时空联合分布 |
| --- | --- | --- |
| 横轴 | `g_E`，cm/km | `g_t`，cm/day |
| 纵轴 | `g_N`，cm/km | `g_S`，cm/km |
| 单个样本 | 某日某格点的东西/南北梯度对 | 某日某格点的时间梯度和同日空间幅值 |
| 有效条件 | 五点空间模板全部有效 | 时间两日及五点空间模板全部有效 |
| 有雪条件 | 五点至少一个雪深 >0 | 时间模板或空间模板中至少一个雪深 >0 |
| 格子颜色 | 该二维 bin 内的原始样本数，颜色取对数 | 同左 |
| 分箱 | 100 × 100 个等宽 bin | 同左 |

每轴显示范围按本图样本绝对值的 99.5% 分位数确定；有符号轴左右对称，空间幅值轴从零开始。由于这是联合范围，落在图外的总比例可能超过 0.5%，图标题列出实际比例。白色格子表示计数为零。原始二维 bin 计数、边界和总样本数保存在对应 NPZ 文件中。

右图两轴单位不同，仅观察联合分布，**没有将两轴直接合成一个 HOG 方向角**。两张图中的零梯度都保留；图内标签再次说明这一点。

## 一维分布与方向直方图

`01_distributions.png`：上排显示 `g_t` 和 `g_S` 的一维计数分布，同时比较“全部有效”和“有雪参与”的样本；两条曲线分别按各自全体样本数归一化。每图 100 bins、纵轴对数；尾部截取仅用于绘图，不把图内概率重新归一化为 1。

下排为基础 **Histogram of Oriented Gradients**，本轮采用有符号方向和幅值权重：

| 特征 | 时间 HOG | 空间 HOG |
| --- | --- | --- |
| 方向 | `atan(g_t / s_t)`，`s_t=1 cm/day` | `atan2(g_N,g_E)` |
| 角度范围 | -90°至90° | -180°至180°，圆周首尾相接 |
| 方向解释 | 负值减小、正值增加 | 0°东，90°北，±180°西，-90°南 |
| 权重 | `abs(g_t)` | `g_S` |
| 分箱 | 18 个等宽硬分箱，10°/bin | 18 个等宽硬分箱，20°/bin |
| 平坦样本 | 计数分布保留，HOG 权重为零 | 同左 |

时间参考尺度是显式超参数，改变 cm/day 单位或尺度会改变角度分布。空间方向受东西/南北距离换算影响。这里不声称消除了所有振幅影响，也未实施空间 cell/block 或 L2-Hys。它们是供本轮观察的方向统计，未来可在用户指导下扩展成分块描述子。

## 逐月特征与导出

对每个格点，将所有年份的同一公历月样本累积，再按月对方向权重做 L1 归一化。有有效非零梯度的月份，18 个 bin 总和为 1；无梯度或无有效样本的月份为全零，需结合 `*_counts` 和原始权重区分。不同年份的闰日按实际日期计入；不存在把年内日序号硬对齐的问题。

`03_monthly_hog.png` 展示区域内逐月方向分布：先跨格点汇总原始权重，再按月归一化。因此梯度强的像元权重较高；不是每个像元等权平均。图内有完整说明，左右色标独立。

`hog_features.npz` 保存：

- `temporal_features`、`spatial_features`：各 **(7353, 216)**，216 = 12 公历月 × 18 bins。两者独立保存，未设定联合特征的相对权重。
- `temporal_raw`、`spatial_raw`：**(12, 57, 129, 18)**，保留幅值信息。
- `temporal_l1`、`spatial_l1`：同样形状，逐像元逐月 L1。
- `temporal_counts`、`spatial_counts`：**(12, 57, 129)**，有效有雪模板数，含梯度恰为零者。
- `latitude`、`longitude` 及两个角度边界数组。特征行按纬度、经度网格 C-order 展平，行号 `r*129+c`。

```python
from pathlib import Path
import numpy as np

path = Path("outputs/exp-0005-primary-2000-2014/hog_features.npz")
with np.load(path) as features:
    temporal = features["temporal_features"]
    spatial = features["spatial_features"]
    latitude = features["latitude"]
    longitude = features["longitude"]
```

本轮 216 维遵循上述逐月探索定义，与 README 中尚待明确分块规则的 288 维方案分别记录。
